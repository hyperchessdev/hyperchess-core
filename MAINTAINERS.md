# Maintainers

HyperChess Core is maintained by the **HyperChess Developer Team** under the
[BDFL governance model](GOVERNANCE.md) currently in effect.

| Area | Maintainer | Notes |
| --- | --- | --- |
| Project-wide (all crates, packages, releases, governance) | HyperChess Developer Team | Founding maintainer group — see [`GOVERNANCE.md`](GOVERNANCE.md) |

This table grows as contributors earn committer/maintainer status per the
[role ladder](GOVERNANCE.md#role-ladder). If you've been contributing steadily and don't see
yourself here, ask — advancement isn't automatic and we'd rather you ask than wonder.

## What a maintainer does

- Reviews and merges pull requests in their area, per [`CONTRIBUTING.md`](CONTRIBUTING.md).
- Triages incoming issues, aiming for a fast, honest first response.
- Participates in [design notes](GOVERNANCE.md#rfc--design-note-process) for rules, format,
  licensing, or security-policy changes, and holds the line on the
  [search safety invariants](docs/search-architecture.md#safety-invariants-the-checklist).
- Upholds [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md).
- Credits contributors by name in release notes and [`ACKNOWLEDGMENTS.md`](ACKNOWLEDGMENTS.md).
