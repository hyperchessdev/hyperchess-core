# HyperChess Core

A 12×12 chess variant engine — board representation, move generation, and search — plus a driver
(CLI, UCI, and a stateless REST/OpenAPI service) and a TypeScript/WASM SDK for embedding it anywhere.

**Status: early bootstrap.** This repo is being extracted from a private engine
(`kyrpy-hyperchess-rust`) per
[`docs/hyperchess-core-extraction-plan.md`](docs/hyperchess-core-extraction-plan.md). No engine,
driver, or SDK code has landed yet — see that plan for the full architecture, phased rollout, and
current status.
